# 내 Slack 워크스페이스에 OKRI 연결하기

OKRI는 고객마다 별도의 Slack Bot Token을 발급받아 워크스페이스별로 분리 보관한다. 다른 고객의 Slack이나 운영자의 테스트 Slack과 연결되지 않는다.

## 연결 방법

1. OKRI에서 연결할 워크스페이스의 Owner 또는 Admin으로 로그인한다.
2. **앱 연동 → Slack 연결**을 누른다.
3. Slack 승인 화면에서 본인이 사용하는 Slack 워크스페이스를 선택한다.
4. 요청 권한을 확인하고 승인한다.
5. OKRI로 돌아오면 요일·시간·대상 멤버·공유 채널만 선택하고 **설정 완료**를 누른다.

고객이 Slack 개발자 화면을 열거나 훅 URL, Client ID, Client Secret을 입력할 필요는 없다.

## 연결 후 설정

- OKRI와 Slack 이메일이 같은 멤버는 자동으로 연결된다.
- **Slack 멤버 연결 확인**에서 미연결 원인을 확인한다. 이메일이 유일하게 일치하는 계정만 연결하며, 기존 수동 연결은 재동기화해도 보존한다.
- 이메일이 다르면 Owner/Admin이 해당 멤버의 Slack 계정을 선택하고 양쪽 계정을 확인한 뒤 연결할 수 있다. 이름이 같다는 이유만으로 자동 연결하지 않는다.
- 멤버 본인이 Slack에서 `/okri daily`를 입력하고 15분짜리 일회용 링크로 연결할 수도 있다. 이미 다른 멤버에게 연결된 계정은 덮어쓰지 않는다.
- Owner/Admin이 최초 설정에서 알림 대상과 기본 시간, 공유 채널을 한 번에 정한다.
- 공개 채널은 선택하면 봇이 자동 참여하고, 비공개 채널은 봇이 이미 초대된 경우에만 보인다.
- 설정 완료 시 선택 멤버의 다음 DM을 예약하고 설치자와 선택 채널에 테스트를 보낸다.
- 개인별 시간 덮어쓰기는 **고급 설정**에서 관리한다.

## 개인별 데일리

- Slack DM의 **내 업무 선택** 또는 `/okri daily`에서 본인 담당 업무를 불러온다.
- Project는 DRI 또는 실행 담당, Task와 Routine은 본인에게 배정된 미완료 항목만 보인다.
- 오늘 진행할 업무를 선택해 제출한다. 신규 업무는 자동 선택하지 않으며, 선택하지 않은 업무의 상태·기한·담당자는 변경하지 않는다.
- Task가 없는 Project와 Routine도 직접 선택할 수 있다. 데일리 선택만으로 Task를 만들지 않는다.
- 메모·블로커, 오늘 예정 없음 또는 사유가 있는 스킵을 함께 제출할 수 있다.
- 제출 시점의 제목과 상위 항목은 기록에 남는다. 웹 데일리와 같은 선택·권한 정책을 사용한다.

## 허들 메모를 봇 문맥으로 사용하기

- 허들이 끝난 뒤 해당 허들 스레드에서 `@OKRI`를 부르면, 봇은 스레드 메시지와 허들에 연결된 메모 Canvas 본문을 함께 읽는다.
- 봇이 참여할 수 있는 채널의 허들 메모만 읽으며 Canvas 본문은 요청 처리에 필요한 길이로 제한한다. 허들 음성, 자막 또는 전체 녹취를 읽는 기능은 아니다.
- Canvas는 봇 공유만으로 본문 접근이 보장되지 않는다. OKRI는 연결을 승인한 Owner/Admin의 `files:read`, `canvases:read` 읽기 권한을 암호화해 보관하고 허들 Canvas 조회에만 사용한다. 메시지 발송과 다른 봇 동작에는 이 사용자 권한을 사용하지 않는다.
- 기존에 Slack을 연결한 워크스페이스는 Owner 또는 Admin이 **앱 연동 → Slack 권한 업데이트**에서 사용자 읽기 권한을 한 번 추가 승인해야 한다. 승인자는 팀의 허들 Canvas를 실제로 볼 수 있는 계정이어야 한다.
- 권한이 없거나 Canvas 본문을 불러오지 못하면 봇이 메모를 생략하지 않고 필요한 조치를 스레드에 안내한다.

## 연결이 막히는 경우

- **Slack 관리자 승인 필요**: 회사 Slack 정책상 앱 설치 승인이 필요하다. Slack Owner/Admin에게 승인 요청 후 다시 연결한다.
- **이미 다른 OKRI 워크스페이스에 연결됨**: 기존 OKRI 워크스페이스에서 연결을 해제한 뒤 다시 시도한다.
- **권한 업데이트 필요**: OKRI의 **Slack 권한 업데이트**를 눌러 새 권한을 승인한다.
- **사용자 미연결**: **Slack 멤버 연결 확인**에서 원인을 확인하고 이메일 일치 계정 연결 또는 관리자 확인 연결을 사용한다.

한 OKRI 워크스페이스에는 Slack 워크스페이스 하나만 연결된다. 연결을 해제해도 기존 데일리 기록은 보존되지만 예약 DM과 채널 전송은 중지된다.
